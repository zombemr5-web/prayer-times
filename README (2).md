# مواقيت الصلاة — كركوك 🕌

موقع بسيط يعرض مواقيت الصلاة بتوقيت بغداد لمحافظة كركوك، مع عدّاد تنازلي للأذان ثم للإقامة، وأذكار بعد الصلاة وأحاديث نبوية.

## المميزات
- عدّاد تلقائي: «صلاة الظهر تبدأ بعد ...» ثم «الإقامة بعد ...»
- الإقامة: 15 دقيقة بعد الأذان، المغرب 5 دقائق، الفجر 30 دقيقة
- أذكار بعد الصلاة مع عدّاد بالضغط
- أحاديث نبوية تتغير تلقائيًا
- يعمل على الجوال، ويحفظ مواقيت اليوم في المتصفح

## التشغيل
افتح `index.html` في المتصفح (يعمل بدون إنترنت؛ المواقيت تُحسب داخل الجهاز وتتغير تلقائيًا حسب اليوم والشهر).

## النشر على GitHub Pages
1. ارفع `index.html` و `sw.js` و `README.md` إلى مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط مرة واحدة بإنترنت، وبعدها يعمل بدون إنترنت. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## التعديل
كل الإعدادات في أعلى كود JavaScript داخل `index.html` (كائن `CONFIG`):
- `fajrAngle` / `ishaAngle`: زاويتا الفجر والعشاء. قارن النتيجة بتقويم المسجد الرسمي وعدّلها، أو استخدم `adjust` لتقديم/تأخير الأذان بالدقائق.
- `iqama`: دقائق الإقامة لكل صلاة.
- `asrFactor`: العصر (1 جمهور، 2 حنفي).
- `mosque`: اسم المسجد في العنوان.

## المصدر
المواقيت تُحسب بخوارزمية فلكية (نفس طريقة PrayTimes) من إحداثيات كركوك والتاريخ.
